# Noxira People modification and attribution record

Modification date: 2026-10-12.

Noxira People is a modified fork of OrangeHRM Starter 5.9, based on the source published by [orangehrm/orangehrm](https://github.com/orangehrm/orangehrm). The maintained fork is [abdulliciozs/noxira-people](https://github.com/abdulliciozs/noxira-people). The PHP/Symfony backend, Vue frontends, installer, and upstream HR features remain the original application architecture; this project is not a ground-up replacement.

This modification updates the visible name and default brand presentation to Noxira People: logo and favicon assets, default theme colors, document titles, login and installer labels, recruitment-facing fallback marks, and the in-app About notice. Default external social-brand icons are disabled. Administrator-selected custom corporate themes continue to take precedence.
